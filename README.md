- このプロジェクトは [GitHub Pages](https://pages.github.com/) を利用しています。
<br><br>
- アンドロイドの方は、以下QRコードを読み込み、「インストール」ボタンを押してください。
- その後は、画面に従いインストールしてください。
- 「PWA」というアイコンが作られ、そのアイコンによりアプリが立ち上がります。
<br><br>
- iPhoneのかたは、以下QRコードを読み込みんでださい。
- 下部の「・・・」を押下し、次に「共有」を押下。
- 下にスクロールすると、「ホーム画面に追加」があるので、それを押下。
- その後は画面に従い、「webアプリとして開く」をONにして実行する。
- 「PWA」というアイコンが作られ、そのアイコンによりアプリが立ち上がります。
